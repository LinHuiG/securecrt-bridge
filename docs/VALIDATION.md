# 验证记录

验证环境：Windows x64，SecureCRT 9.7.1 x64。测试仅使用已授权的测试会话；公开记录不含服务器地址、账号、会话令牌或终端截图。

## 真实终端

- 0.1.1：自动接入，读取屏幕，执行只读命令；中文、标准错误输出、退出码 7 采集正确。
- 0.1.2：重新启动后自动接入两个会话；退出不再错误地保存暂停状态；最小化时命令到达各自正确的标签页。
- 0.1.3：两个真实 SSH 标签页分别运行带 `sleep 4` 的只读命令。开始标记、中间输出、结束标记全部返回，退出码均为 0。Broker 本机记录的执行区间重叠 **4521 ms**，确认后台并行。所有测试租约已释放。
- 独立 SecureCRT 配置与本机模拟登录测试：80 次连续请求成功；登录脚本同步缓冲导致的画面不刷新问题已复现并修复。

不能用不同服务器的墙上时钟比较并行时间；以上重叠时间全部来自同一本机 Broker。

## 0.1.4 安装界面

- Rust 发布构建成功，22 项自动测试通过。
- 实际 Windows 窗口已显示，核对了中文布局、路径检测、安装／卸载选项、进度栏与日志区域。
- `--installer-self-test` 创建隐藏的本程序窗口，验证真实控件的进度更新、模式切换、卸载时路径锁定、执行期间按钮禁用、错误日志与重试恢复；不执行安装、注册或卸载。
- 无效安装路径在写入前被拒绝。
- 桌面输入接口返回 `GetCursorPos: 0x80070005`，因此本轮未完成鼠标点击目录对话框及真实升级／卸载全过程验收。该限制不能由控件自检替代，未将这些项目标为通过。

之后在实际桌面观察到 0.1.4 安装日志到达 100%，组件注册、会话配置、skill 和本地服务启动完成；API 返回版本 0.1.4、paused=false。安装过程由用户操作完成。本轮没有执行真实卸载，也尚未验证这次安装后的新 SSH 接入。

0.1.5 增加日志中的完整路径，沿用 0.1.4 的界面与已验证的终端通信实现；发布构建和隐藏控件自检通过。详细进度来自真实安装步骤。

## 0.1.6 自主恢复与授权说明

- Windows GNU 工具链构建成功，27 项自动测试通过。
- 新增恢复测试覆盖：Ctrl+C 单次派发、原任务锁保留、错误 owner/任务 ID/过期租约拒绝、运行中及暂停时拒绝恢复、原任务迟到结果取消未发送的恢复输入、恢复结果未知后的显式确认。
- COM 模拟对象验证恢复负载只调用一次 `Screen.Send`，不包装 shell 命令，不读取结束标记。
- 独立数据目录运行真实 Broker EXE，通过 CLI 与 HTTP 模拟终端上报，完成“未知任务 → 普通输入被拒绝 → interrupt → 新快照 → acknowledge → 后续命令成功”的完整流程。
- 安装器隐藏控件自检通过，未执行安装或注册变更。skill 格式校验通过。
- 当前用户的只读命令规则通过 `codex execpolicy check` 校验：查询命令匹配，`exec/input/interrupt` 不匹配。规则是否命中还取决于宿主实际提交的命令形式，重启后加载。
- 本轮没有对真实远程 SSH 会话发送 Ctrl+C，也没有关闭用户正在使用的 SecureCRT 或执行新版本安装。

HTTP 鉴权及分段请求、中文 JSON、重复头拒绝；租约与请求 ID、过期任务不发送、暂停取消未发送任务、未知结果保持占用；配置按键恢复与保留用户修改；COM 生命周期、终端标记与转义、中文和退出码、延时输出完整性及超时不重试；便携版目录检测、Windows 路径大小写兼容。
